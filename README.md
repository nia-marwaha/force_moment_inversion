This project uses LSForce and LSData architecture (https://code.usgs.gov/ghsc/lhp/lsforce) for Bayesian inversion of seismic signals. 
This needs to be downloaded separately for code to run

This repository contains the files necessary for the retrieval of Green's functions from Syngine and bayesian inversion and model comparison. 
The file bayseian.py contains original code, the file edited_lsforce.py contains code from the LSForce repository with additions for moment 
Green's functions retreivals. 

The notebooks contain examples of the inversion run on given synthetic data and a real glacial event.
